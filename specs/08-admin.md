# 08. 관리자 모드

관련 요구사항: ADM-1 ~ ADM-8

---

## 1. 목적

관리자는 앱에 데이터를 넣고(지식 베이스·참조값), 기능을 조정하고(LLM·RAG·계산 파라미터), 사용자를 승인한다.
**튜닝 가능한 값은 전부 DB 에 있고 이 화면에서 바꾼다**(`AGENTS.md` §1).

## 2. 메뉴

- **ADM-1** 관리자 모드는 `/admin/*` 아래에 있고 `role == ADMIN` 만 들어온다. 프론트 가드와 별도로 모든 관리자 API 가 `IsAdminRole` 을 확인한다.
- **ADM-2** 데스크톱은 좌측 사이드바, 모바일은 오프캔버스 메뉴(`11` §4).

## 3. 개요 (ADM-3)

- **ADM-3** 첫 화면에 "지금 손봐야 할 것"을 모은다: 승인 대기 N건, 색인 실패 N건, LLM 키 없음/연결 오류, 임시값 참조 데이터 N건.
  각 항목을 누르면 해당 메뉴로 간다.

## 4. 설정 (ADM-4, ADM-5)

- **ADM-4** 설정은 키-값(`Setting`)으로 저장하고, 키마다 타입·기본값·범위·설명·분류를 코드 시드로 정의한다.
  화면은 분류별로 묶고, 범위를 벗어나면 저장하지 않는다. "기본값으로 되돌리기"를 항목별로 제공한다.
- **ADM-5** 설정 키 전체 목록 (RAG 튜닝 설정은 기술 프롬프트 요구 — 시스템 프롬프트 포함 전부 DB):

- 계산 계수는 `Setting` 이 아니라 버전 있는 `CalcParameterSet` 에 둔다(`06` §5).
- 임베딩 모델은 설정이 아니다 — 환경 변수, 화면에는 읽기 전용(`03` §5).

### 4.1 시스템 프롬프트 시드 문안

```
당신은 HRSG(배열회수보일러) 세정·성능 전문 상담 도우미입니다.
현장 엔지니어가 이해하기 쉽게, 핵심부터 간결하게 답하세요.
제공된 자료에 근거해 답하고, 수치가 필요하면 계산 도구를 사용하세요.
```

- 이 문안 앞에 코드의 고정 보호 규칙이 항상 붙는다(`02` §4). 관리자가 문안을 지워도 보호 규칙은 남는다.
- 화면에 "보호 규칙(편집 불가)" 요약을 읽기 전용으로 함께 보여 준다.

## 5. 감사 로그 (ADM-6)

- **ADM-6** 다음 변경을 전부 기록한다: 가입 승인·반려, 사용자 수정·비활성화·비밀번호 초기화, 문서 생성·수정·삭제·재색인,
  민감어, LLM 설정(키는 "변경됨"만), 설정값, GT 모델·공법·SMP·파라미터 세트, 체크리스트 템플릿.
- 기록: 시각, 관리자, 대상 종류·ID, 동작, 변경 전·후 스냅샷(비밀번호·API 키·문서 원본 제외).
- 필터: 기간, 관리자, 대상 종류. 감사 로그는 수정·삭제할 수 없다.

## 6. 동시 편집 (ADM-7)

- **ADM-7** 같은 대상을 두 관리자가 동시에 고치면 나중 저장이 `409 CONFLICT` 를 받는다(`updated_at` 또는 `version` 비교).
  화면은 "다른 관리자가 먼저 수정했습니다. 새로고침 후 다시 시도하세요"를 보여 준다.

## 7. 데이터 초기화 (ADM-8)

- **ADM-8** `seed_defaults` 는 멱등이다. 이미 있는 값은 덮어쓰지 않는다. 시드 항목: 기본 관리자, 설정 키, LLM 공급자 3종(키 없음),
  가상 GT 모델·공법·파라미터 세트, 체크리스트 템플릿, 시스템 프롬프트.
- 가상 지식 베이스 문서는 시드가 아니라 별도 명령(`load_virtual_kb`)으로 넣는다 — 운영에서 실수로 들어가지 않게(`14` §3).

## 8. 수용 기준 (AC)

- [ ] AC-08-1 USER 권한으로 모든 관리자 API 가 403 이다(엔드포인트 전수 테스트).
- [ ] AC-08-2 범위를 벗어난 설정값은 저장되지 않고 이유가 보인다.
- [ ] AC-08-3 설정·참조값·문서 변경이 감사 로그에 남고, API 키·비밀번호 값은 스냅샷에 없다.
- [ ] AC-08-4 개요 화면의 각 경고를 누르면 해당 메뉴로 간다.
- [ ] AC-08-5 두 관리자가 같은 GT 모델을 동시에 고치면 나중 저장이 409 를 받는다.
- [ ] AC-08-6 `seed_defaults` 를 두 번 실행해도 행 수가 늘지 않고, 관리자가 바꾼 값이 덮어써지지 않는다.
