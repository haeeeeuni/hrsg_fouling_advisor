## 3. 결정 기록 (2026-10-10, 다시 제안하지 않는다)

뒤집으려면 새 근거와 함께 먼저 묻는다.

| # | 주제 | 결정 | 근거·대안 |
|---|---|---|---|
| D1 | 이전 대시보드·분석 기능 | **없앤다.** 화면·API 에서 빼고 코드는 전환 단계에서 일괄 삭제(git 이력에 남음) | 새 요구사항에 없음 |
| D2 | 첫 화면 | 공개 **소개 화면**(앱 소개·사용 방법). 로그인 후 기본 이동은 홈(3기능 카드) | 사용자 결정 |
| D3 | 사용자 접근 | 기술 프롬프트의 "로그인 없이 채팅" 대신 **회원가입 + 관리자 승인**. 승인 전 로그인 불가 | 외부인 접근 차단(사용자 결정) |
| D4 | 로그인 형식 | **ID + 비밀번호**, 기본 관리자 `admin` / `admin1234!` (기술 프롬프트대로). 이전의 성명 + 사번 방식 폐기 | 사용자 결정. User 마이그레이션 새로 시작 |
| D5 | 비밀번호 | 최소 8자, 숫자만 금지 | 자가 가입이 생겼으므로 이전 4자 완화를 없앰 |
| D6 | LLM | **3종 중 택1**, 기본 Claude `claude-opus-5-5`, 관리자가 모델 변경 | 기술 프롬프트 |
| D7 | API 키 | 관리자 화면 입력 → DB **암호화 저장**(Fernet, `FIELD_ENCRYPTION_KEY`), 응답엔 끝 4자만 | 기술 프롬프트 + 보안 보강 |
| D8 | 임베딩 | **로컬 다국어 경량 모델**(ONNX, `multilingual-e5-small` 1순위) + **pg_trgm 키워드 하이브리드**. 구현 초기에 메모리·적중률 실측, 미달 시 외부 임베딩 API | 채팅 LLM 과 분리·추가 키 불필요·외부 전송 축소 |
| D9 | 임베딩 모델 설정 위치 | 환경 변수(관리자 화면은 읽기 전용) — "RAG 설정 전부 DB"의 유일한 예외 | 벡터 차원이 스키마에 묶여 바꾸려면 마이그레이션 + 전체 재색인 필요 |
| D10 | 보호 장치 | 고정 보호 규칙·숫자 근거 검사·민감어 가림은 **코드**에 둔다. 관리자 시스템 프롬프트로 끌 수 없다 | 검수 4·6, 프롬프트 인젝션 대비 |
| D11 | Bootstrap | 프롬프트의 5.0 대신 **5.3 유지** | 라이트/다크 컬러 모드가 5.3 부터 |
| D12 | 비동기 | **Celery + Redis 유지**(문서 색인) | 큰 PDF 색인은 요청 시간 초과 위험 |
| D13 | 응답 방식 | 1차는 **비스트리밍** 동기 요청 | DRF·Gunicorn 구성 단순 |
| D14 | 계산식 | 이전 앱 편익 모델을 입력 기반으로 바꾼 **임시 식**(`05` §6). 실무 확정 후 교체 | 사용자 결정 |
| D15 | 관리자가 바꿀 수 있는 계산 요소 | 계수·참조표·공법 표(버전 관리). **식 구조는 코드**(`formula_version`) | 수식 편집기는 검증·보안 부담 대비 이득 작음 |
| D16 | GT 한계표 | 모델별 한계표로 운전 상태 판정. 지금은 **가상 모델 A/B/C**(실존 모델명 사용 안 함) | 사용자 결정 |
| D17 | 외부 API 전송 | 일단 외부 LLM API 사용, **가상 데이터로만 검증** | 실무 논의 전 |
| D18 | SMP | 관리자 수동 등록(값·기준일·출처), 항상 기준일·출처 표시. KPX 자동 수집은 범위 밖 | 공식 가격 오인 방지 |
| D19 | 대화 기록 | 본인만 열람. 관리자는 사용량만 | 개인 질문 보호 |
| D20 | 질문 한도 | 사용자 하루 50회(설정) | API 비용 |
| D21 | 체크리스트 | 요청 건은 본인만, 복사 문구 한·영, 템플릿은 생성 시 복사 | 재현성·단순성 |
| D22 | 원본 파일 저장 | PostgreSQL BinaryField | PaaS 디스크는 재배포 시 사라짐 |
| D23 | UI | AdminHMD 토큰 유지 + 다크 토큰 이식. 사용자 화면은 상단 바, 관리자는 사이드바 | 모바일 우선 |
| D24 | 검수 자료 | 받기 전까지 가상 데이터를 만들어 검증(`14` §3) | 수령 시점 미정 |
| D25 | 이메일 | 보내지 않는다(복사만, 알림은 앱 내 배지) | 이전 결정 유지 |

이전 앱의 결정 중 **유지되는 것**: 이메일 미구현, 편익 정지 손실 마진 기준(`fuel_cost_ratio` 0.792), 설정값 DB 원칙, 세션 쿠키 + CSRF, 감사 로그, AdminHMD.
**의미가 없어진 것**: GBR/TabPFN, 기준 기간 다중 창, `INSUFFICIENT_BASELINE`, joblib 아티팩트 보류.
