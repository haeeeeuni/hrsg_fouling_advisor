# 07. 오염도 지수 산출 및 등급 판정

관련 요구사항: FR-U-09, FR-U-10, FR-A-04

---

## 1. 목적
실측값과 기대값의 편차를 0~100 범위의 단일 지수로 환산하고, 등급으로 판정한다.

## 2. 산출 절차

```
[1] 잔차 계산        r_dp(t) = dp_meas(t)  - dp_exp(t)
                     r_st(t) = stack_meas(t) - stack_exp(t)
[2] 평활화           이동 중앙값/평균 (기본 24시간 윈도)
[3] 정규화           z 또는 상대편차 → 0~100 스케일
[4] 가중 합산        FI_raw = w_dp × S_dp + w_st × S_st
[5] 클리핑           FI = clip(FI_raw, 0, 100)
[6] 군집 가중 집계   군집별 FI → 표본 수 가중 평균 = 대표 FI
```

## 3. 단계별 상세

### 3.1 잔차 계산
- 유효(STEADY) 구간의 각 포인트에 대해 계산한다.
- 차압 계측이 없는 호기는 `gt_backpressure_kpa` 기준으로 동일하게 계산한다.

### 3.2 평활화
- 잔차는 노이즈가 크므로 `smoothing_window_h`(기본 24시간) 이동 중앙값을 적용한다.
- 일 단위 대표값(일별 중앙값)으로 집계한 `FI_daily` 시계열을 별도로 산출하여 추세 분석과 시각화에 사용한다.

### 3.3 정규화 — 두 방식 제공 (기본 `SIGMA`)

**(a) `SIGMA` 방식 — 잔차 표준편차 기준 (기본)**
```
z_dp = (r_dp_smoothed - μ_dp) / σ_dp        # μ, σ 는 ModelVersion에 저장된 청정 기준 잔차 통계
S_dp = clip(z_dp / z_ref, 0, 1) × 100
```
- `z_ref` = `sigma_ref`(기본 6.0): “청정 기준 잔차의 6σ 만큼 벗어나면 100점”
- **음의 잔차(기대보다 낮음)는 오염이 아니므로 0으로 클리핑**한다.

**(b) `RELATIVE` 방식 — 상대 편차 기준**
```
d_dp = (dp_meas - dp_exp) / dp_exp × 100      [%]
S_dp = clip(d_dp / dp_ref_pct, 0, 1) × 100
```
- `dp_ref_pct`(기본 30%): 기대 차압 대비 30% 상승 시 100점
- `st_ref_c`(기본 15 ℃): 기대 스택온도 대비 15 ℃ 상승 시 100점
- 스택온도는 상대(%)보다 절대 편차(℃)가 물리적으로 자연스러우므로 ℃ 기준을 쓴다.

정규화 방식과 기준값(`sigma_ref`, `dp_ref_pct`, `st_ref_c`)은 모두 **관리자 설정값**이며 호기별 오버라이드가 가능하다.

### 3.4 가중 합산
```
FI_raw = w_dp × S_dp + w_st × S_st ,   w_dp + w_st = 1
```
| 설정 | 기본값 | 비고 |
|------|--------|------|
| `w_dp` (차압 가중치) | 0.6 | 차압 계측이 있는 호기 |
| `w_st` (스택온도 가중치) | 0.4 | |
| 차압 미계측(배압 대체) 호기 | `w_dp=0.4`, `w_st=0.6` 권장 기본 | 관리자 조정 |

- 가중치 합이 1이 아니면 저장 시 자동 정규화하고 경고를 표시한다.
- 한쪽 신호가 결측이면 나머지 하나의 가중치를 1로 재정규화하고, 결과에 “단일 신호 기반” 표시를 남긴다.

### 3.5 클리핑
`FI = min(max(FI_raw, 0), 100)` — 최소 0, 최대 100 (요구사항 명시).

### 3.6 군집 가중 집계
```
FI_unit = Σ (n_c × FI_c) / Σ n_c          # c: 군집, n_c: 해당 군집 유효 포인트 수
```
- 희소 군집(표본 < `min_cluster_points`)은 집계에서 제외하거나 가중치를 낮춘다(설정).
- 화면에는 대표 FI와 함께 **군집별 FI 분해표**를 제공한다.

### 3.7 현재 오염도(Current FI)
- 분석 기간 **최근 `current_window_days`(기본 7일)** 의 `FI_daily` 중앙값을 “현재 오염도 지수”로 정의한다.
- 최근 7일 유효 데이터가 없으면 가장 최근 유효일 기준으로 계산하고 기준일을 함께 표시한다.

## 4. 등급 판정 (FR-U-10)

| 등급 | 범위 | 색상 | 의미 |
|------|------|------|------|
| 정상 (NORMAL) | FI < 30 | 초록 | 세정 불필요 |
| 주의 (CAUTION) | 30 ≤ FI < 60 | 노랑 | 추세 감시, 세정 계획 검토 |
| 경고 (WARNING) | FI ≥ 60 | 빨강 | 세정 권고 |

- 경계값 30, 60은 **DB 설정값**(`grade_caution_min`, `grade_warning_min`)이며 관리자 변경 가능. 기본 임계치(`fouling_threshold`)는 60으로 경고 경계와 동일하되 독립 설정한다.
- 등급 경계 변경 시 `grade_caution_min < grade_warning_min ≤ 100` 유효성을 검증한다.
- 등급이 변경된 날짜를 `FI_daily` 시계열에 마커로 표시한다.

## 5. 신뢰도 표시
각 FI 값에 신뢰도 등급을 부여해 UI에 함께 표시한다.

| 신뢰도 | 조건 |
|--------|------|
| 높음 | 모델 R² 양호 + 유효 포인트 충분 + 도메인 내 |
| 보통 | 지표 중 하나가 ‘주의’ |
| 낮음 | 모델 지표 불량 또는 유효 포인트 부족 또는 `OUT_OF_DOMAIN` 비율 > 30% |

## 6. 산출물 데이터 모델

```
FoulingIndexPoint
  - analysis_run (FK)
  - date (일 단위) 또는 timestamp
  - cluster_key (nullable, 전체 집계는 null)
  - fi_value          : 0~100
  - score_dp / score_st        : 정규화 점수 (0~100)
  - residual_dp / residual_st  : 원시 잔차
  - expected_dp / expected_st  : 기대값
  - measured_dp / measured_st  : 실측값
  - sample_count
  - confidence : 'HIGH'|'MEDIUM'|'LOW'
  - grade : 'NORMAL'|'CAUTION'|'WARNING'
```

원시 잔차와 기대/실측값을 함께 저장해 **역추적과 검증이 가능해야 한다.**

## 7. 예외 처리
| 상황 | 처리 |
|------|------|
| `σ_dp` 또는 `σ_st` 가 0에 가까움 | 하한 `1e-6` 적용, 신뢰도 ‘낮음’ 표시 |
| 두 신호 모두 결측 | 해당 일자 FI 미산출(`null`), 시계열에 빈 구간으로 표시 |
| FI가 장기간 100에 고정 | “정규화 기준값 과소 설정 가능성” 경고와 함께 `dp_ref_pct`/`sigma_ref` 재검토 안내 |
| 세정 직후에도 FI가 높게 유지 | “청정 기준 기간 재지정 필요” 경고 |

## 8. 수용 기준 (AC)
- [ ] AC-07-1: 오염이 없는 합성 데이터에서 FI가 0~10 범위에 머문다.
- [ ] AC-07-2: 잔차를 선형 증가시키면 FI가 단조 증가한다.
- [ ] AC-07-3: 세정 이벤트 직후 FI가 급락한다(샘플 데이터).
- [ ] AC-07-4: FI가 0 미만 또는 100 초과로 저장되는 경우가 없다.
- [ ] AC-07-5: 관리자가 `w_dp`를 0.8로 바꾸면 재분석 결과 FI가 그에 맞게 변한다.
- [ ] AC-07-6: 등급 경계를 25/55로 바꾸면 등급 판정이 즉시 달라진다.
