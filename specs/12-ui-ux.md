# 12. UI/UX

관련 요구사항: UI-3 ~ UI-6

---

## 1. 원칙

현장 엔지니어가 **한눈에** 판단할 수 있어야 한다.

- **UI-3 큰 숫자 + 상태 색.** 계산기 결과의 핵심(상태, 일 손실, 회수 기간)은 화면에서 가장 큰 글자로 보여 준다.
- **UI-4 한국어 기본.** UI 문구는 한국어다. 챗봇 답변만 질문 언어를 따른다(`02` CHAT-5).

## 2. 테마

**AdminHMD 디자인 토큰을 유지**하고 다크 모드를 추가한다(이전 앱 `archive/v1-fouling-advisor/20-ui-ux.md` 의 토큰·접근성 실측을 이어받는다).

- 테마 정의는 `frontend/src/assets/styles/` 의 테마 CSS 한 곳에 둔다. Bootstrap `--bs-*` 변수를 재정의한다.
- 셸 클래스는 테마 중립 `ui-` 접두를 쓴다(테마 교체 비용 최소화 — 이전 앱의 교훈).
- 폰트는 시스템 스택. 라틴 폰트 → 한글 폰트 순서를 지킨다(바꾸면 숫자까지 한글 폰트로 렌더된다).

### 2.1 라이트/다크 (UI-5)

- **UI-5** Bootstrap 5.3 의 컬러 모드(`<html data-bs-theme="light|dark">`)를 쓴다. 이 때문에 Bootstrap 을 5.0 이 아니라 **5.3** 으로 유지한다.
  - AdminHMD 가 제공하는 다크 토큰 세트(`html[data-theme="dark"]`)를 `data-bs-theme="dark"` 선택자로 옮긴다.
  - 기본값은 OS 설정(`prefers-color-scheme`), 헤더 토글로 바꾸면 `localStorage` 에 저장한다.
  - **Chart.js 는 CSS 변수를 따라가지 않는다.** 축·격자·범례·툴팁 색을 테마 변경 시 JS 에서 다시 설정한다(`useChartTheme` 컴포저블).
  - HRSG 도식(SVG)은 `currentColor` 와 CSS 변수로 그려 테마를 따르게 한다.
  - 페이지 로드 시 깜빡임(FOUC)을 막으려고 `index.html` 의 인라인 스크립트로 테마를 먼저 적용한다.

## 3. 상태 색 (UI-6)

- **UI-6** 상태 색은 도메인 의미를 가지므로 테마보다 우선한다.

  | 상태 | 색 | 아이콘 | 문구 |
  |---|---|---|---|
  | 정상 | 초록 (`--bs-success`) | 원형 체크 | 정상 |
  | 주의 | 주황 (`--bs-warning`) | 삼각 느낌표 | 주의 |
  | 위험 | 빨강 (`--bs-danger`) | 팔각 정지 | 위험 |

  - 운전 상태 판정(정상/경보/트립)은 정상/주의/위험 색에 대응한다(`05` §3.2).
  - **색만으로 정보를 전달하지 않는다.** 아이콘과 문구를 항상 함께 쓴다(색각 이상 대응).
  - 테마 템플릿의 의미 색은 가져오지 않는다(AdminHMD 의 success 는 청록이라 "정상"으로 읽히지 않는다).
- 다크 모드에서도 상태 색의 명암비를 따로 확인한다(§4).

## 4. 접근성·대비

- 본문·보조 텍스트·버튼·상태 배지는 **WCAG AA 4.5:1 이상**(큰 숫자는 3:1). 라이트·다크 각각 실측해 이 문서에 기록한다.

  실측(2026-10-10, 브라우저 계산값):

  | 대상 | 라이트 | 다크 |
  |---|---|---|
  | 본문 / 배경 · 카드 | 13.69 · 14.68 | 14.42 · 13.14 |
  | 보조 텍스트 / 배경 · 카드 | **4.51** · 4.83 | 7.79 · 7.10 |
  | 링크·강조 글자 / 배경 · 카드 | 4.82 · 5.17 | 7.48 · 6.82 |
  | 기본 버튼(흰 글자 / primary) | 5.17 | 5.17 |
  | 배지 정상 · 주의 · 위험 | 4.53 · 12.88 · 4.53 | 4.53 · 12.88 · 4.53 |

  라이트 보조 텍스트가 4.51 로 기준선에 가장 가깝다 — `--admin-muted` 를 더 밝게 바꾸면 미달한다.
  다크에서 primary(#2563EB)는 글자로 쓰면 대비가 모자라 글자용 `--admin-primary-text`(#7AA7FF)를 따로 둔다.
- 키보드만으로 모든 기능을 쓸 수 있다. 포커스 링을 지우지 않는다.
- 게이지·도식에는 같은 정보를 텍스트로도 둔다(스크린리더용 `aria-label`).

## 5. 반응형

- 지원 폭: **360px(모바일) ~ 1920px**. 360px 에서 가로 스크롤이 생기지 않는다(표는 표 자체만 가로 스크롤).
- 터치 대상은 최소 44×44px.
- 기준 뷰포트: 데스크톱 1280×800, 모바일 390×844(E2E 와 동일, `14` §5).

## 6. 이용 안내 표시

- 임시 참조값 사용 결과: 결과 영역 상단에 정보 배너 "임시 참조값을 사용한 결과입니다. 참고용으로만 보세요."(`06` REF-6)
- SMP: 값 옆에 기준일·출처, 추정·사용자 입력 배지(`06` REF-4)
- 챗봇: 입력창 아래에 "고객사·발전소·개인 정보를 입력하지 마세요"
