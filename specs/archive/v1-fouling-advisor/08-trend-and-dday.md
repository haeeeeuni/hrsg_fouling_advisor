# 08. 오염도 추세 예측 및 임계치 도달 예상일(D-day)

관련 요구사항: FR-U-11

---

## 1. 목적
`FI_daily` 시계열의 진행 추세를 모델링하여 임계치(기본 60) 도달 예상일을 산출하고, 세정 계획 수립의 근거를 제공한다.

## 2. 입력
- `FI_daily` 시계열 (일자, FI, 표본 수, 신뢰도)
- 최근 세정 이벤트 일자 (있으면 그 **이후 구간만** 사용)
- 임계치 `fouling_threshold` (기본 60, 설정값)

## 3. 추세 구간 결정
1. 가장 최근 세정 이벤트 이후의 데이터만 사용한다(오염은 세정에서 리셋되므로 세정 전후를 섞으면 안 된다).
2. 세정 이력이 없으면 최근 `trend_window_days`(기본 180일) 구간을 사용한다.
3. 사용 가능한 유효 일자 수가 `min_trend_points`(기본 30일) 미만이면 **추세 예측을 제공하지 않고** “데이터 부족” 안내를 표시한다.

## 4. 추세 모델

세 가지를 산출하고 그 중 최적 모델을 자동 선택한다(선택 기준: 검증 구간 MAE 최소, 동률이면 단순한 모델 우선).

| 코드 | 형태 | 수식 | 비고 |
|------|------|------|------|
| `LINEAR` | 선형 | `FI(t) = a + b·t` | 기본, 해석 용이 |
| `ROBUST` | 로버스트 선형 | Theil–Sen 또는 Huber | 이상점에 강함 |
| `EXPONENTIAL` | 포화형 | `FI(t) = C·(1 - exp(-k·t))` 또는 2차 다항 | 오염 진행이 가속/둔화하는 경우 |

- `t` 단위는 **일(day)**, 기준점은 추세 구간 시작일.
- 회귀 가중치: 표본 수와 신뢰도를 가중치로 사용(`sample_weight`).
- 자동 선택 결과와 함께 사용자가 모델을 수동 선택할 수 있다.

## 5. D-day 산출

```
목표: FI(t*) = threshold 를 만족하는 최소 t* (t* > 최근 관측일)
D-day = t* 날짜 - 오늘(또는 데이터 마지막 일자)
```

### 규칙
| 상황 | 결과 표시 |
|------|-----------|
| 현재 FI ≥ 임계치 | **“이미 도달”** — D-day = 0, 초과 일수(며칠째 초과 중)를 함께 표시 |
| 기울기 `b ≤ 0` 또는 통계적으로 유의하지 않음(p > 0.05) | **“도달 예측 불가 — 추세 미확인”**, D-day = null |
| 예측 도달일이 `max_forecast_days`(기본 730일) 초과 | **“2년 내 도달 예상 없음”** |
| 정상 | `D-day = N일`, 예상 도달일자 `YYYY-MM-DD` |

### 신뢰구간
- 회귀 예측의 95% 예측구간을 이용해 **도달일의 하한/상한**을 산출한다.
- 표시 형식 예: `D-84일 (2025-12-13, 신뢰구간 2025-11-02 ~ 2026-02-01)`
- 신뢰구간 폭이 D-day의 2배를 넘으면 “불확실성 높음” 배지를 표시한다.

## 6. 부가 산출 지표
| 지표 | 정의 | 용도 |
|------|------|------|
| 오염 진행률 | `b` (FI/일) | 오염 속도 비교 |
| 주간 증가량 | `b × 7` | 보고서 표현 |
| 등급 전환 예상일 | 주의(30), 경고(60) 각 경계 도달일 | 단계별 계획 |
| 추세 적합도 | R², MAE | 예측 신뢰도 |
| 마지막 세정 이후 경과일 | – | 세정 주기 비교 |

## 7. 시각화
- FI 시계열 실선 + 추세선(점선) + 예측 구간 밴드(반투명)
- 등급 경계 수평선(30, 60) 및 임계치 라인
- 세정 이벤트 수직 마커
- 예상 도달점에 마커와 라벨

## 8. 데이터 모델
```
TrendForecast
  - analysis_run (FK)
  - model_type : 'LINEAR'|'ROBUST'|'EXPONENTIAL'
  - fit_start / fit_end
  - coefficients : JSON
  - slope_per_day
  - r2 / mae
  - p_value
  - threshold_used
  - current_fi
  - eta_date (nullable) / eta_days (nullable)
  - eta_lower_date / eta_upper_date
  - caution_eta_date / warning_eta_date
  - status : 'OK'|'ALREADY_EXCEEDED'|'NO_TREND'|'BEYOND_HORIZON'|'INSUFFICIENT_DATA'
```

## 9. 예외 처리
| 상황 | 처리 |
|------|------|
| 추세 구간에 세정 이벤트가 섞여 있음 | 가장 최근 세정 이후로 자동 절단하고 안내 메시지 표시 |
| FI 시계열에 큰 결측 구간 | 결측 일자는 회귀에서 제외, 결측 비율을 표시 |
| 지수 모델 수렴 실패 | 선형으로 폴백 |

## 10. 수용 기준 (AC)
- [ ] AC-08-1: 선형 증가 합성 FI 시계열에서 D-day가 이론값과 ±5일 이내로 일치한다.
- [ ] AC-08-2: FI가 감소 추세일 때 “도달 예측 불가”로 표시된다.
- [ ] AC-08-3: 세정 이벤트 이전 데이터가 추세 적합에 포함되지 않는다.
- [ ] AC-08-4: 임계치를 60에서 50으로 바꾸면 D-day가 짧아진다.
- [ ] AC-08-5: 유효 일자 30일 미만이면 추세·D-day 대신 데이터 부족 안내가 표시된다.
