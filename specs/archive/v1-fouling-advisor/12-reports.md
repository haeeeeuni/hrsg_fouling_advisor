# 12. 리포트 — 세정 전후 비교 및 PDF/엑셀 출력

관련 요구사항: FR-U-15, FR-U-16, TR-05

---

## 1. 목적
분석 결과를 내부 보고 근거 자료로 사용할 수 있도록, 세정 효과를 공정하게 비교하고 한글이 깨지지 않는 PDF·엑셀 파일로 내보낸다.

---

## 2. 세정 전후 비교 리포트 (FR-U-15)

### 2.1 비교 원칙
> **같은 운전 구간끼리만 비교한다.**
부하·외기 조건이 다르면 차압과 스택온도가 자연히 달라지므로, 조건을 맞추지 않은 비교는 무의미하다.

### 2.2 비교 절차
```
[1] 대상 세정 이벤트 선택 (CleaningEvent)
[2] 비교 구간 설정
     세정 전 : cleaned_at − (before_offset_days + window_days) ~ cleaned_at − before_offset_days
     세정 후 : cleaned_end_at + after_offset_days ~ + after_offset_days + window_days
     기본값  : window_days = 30, before_offset_days = 0, after_offset_days = 1
[3] 양 구간 모두 정제 + STEADY 필터 적용
[4] 군집 할당 (동일 ClusterDefinition 사용)
[5] 공통 군집만 추출 (양쪽 모두 표본 ≥ min_cluster_points)
[6] 군집별 지표 비교 → 표본 가중 종합
```

### 2.3 비교 지표
| 지표 | 세정 전 | 세정 후 | 개선량 | 개선율 |
|------|---------|---------|--------|--------|
| 오염도 지수 FI | 64.2 | 12.8 | −51.4 | −80.1% |
| 평균 차압 (kPa) | 3.82 | 2.71 | −1.11 | −29.1% |
| 차압 잔차 (kPa) | +1.05 | +0.08 | −0.97 | – |
| 평균 스택온도 (℃) | 112.4 | 104.1 | −8.3 | −7.4% |
| 스택온도 잔차 (℃) | +9.1 | +0.9 | −8.2 | – |
| 평균 GT 출력 (MW) | 148.2 | 151.0 | +2.8 | +1.9% |
| 유효 포인트 수 | 2,104 | 2,388 | – | – |

- 잔차 기반 비교를 **주 지표**로, 원시 평균 비교는 참고 지표로 표기한다(운전 조건 차이를 보정하므로).
- 통계적 유의성: 군집별 잔차 평균 차이에 대해 t-검정(또는 Mann-Whitney U)을 수행하고 p-value를 표기한다.

### 2.4 비교 시각화
- 군집별 전/후 잔차 그룹 막대 차트
- 전/후 차압·스택온도 분포 박스플롯
- FI 시계열에서 비교 구간을 음영 처리

### 2.5 실적 검증
- 세정 전 분석에서 예측했던 회수 편익 vs 실제 회복량 기반 편익을 나란히 표시한다(예측 편익 이력이 있는 경우).
- 회복률 = `(FI_before − FI_after) / FI_before`

### 2.6 예외
| 상황 | 처리 |
|------|------|
| 공통 군집 없음 | “비교 가능한 동일 운전 조건 구간이 없습니다.” + 윈도 확대 제안 |
| 세정 후 데이터 부족 | 사용 가능한 기간까지만 비교하고 기간을 명시 |
| 세정 전후 모델 버전이 다름 | 동일 모델 버전으로 재계산하여 비교(기준 통일), 사용 버전을 명시 |

## 3. PDF 리포트 (FR-U-16)

### 3.1 기술 요건 — 한글 깨짐 방지 (필수)
- 라이브러리: **ReportLab**(권장) 또는 WeasyPrint.
- 한글 폰트를 저장소에 동봉하고 **명시적으로 등록**한다.
  - 폰트: 나눔고딕(`NanumGothic.ttf`, `NanumGothicBold.ttf`) 또는 Pretendard — OFL/오픈 라이선스만 사용.
  - 경로: `backend/reports/fonts/`
  - ReportLab: `pdfmetrics.registerFont(TTFont('NanumGothic', path))` + `registerFontFamily`
- 모든 스타일(본문, 제목, 표, 차트 축 라벨)에 등록 폰트를 지정한다. 기본 Helvetica 사용 금지.
- 차트 이미지의 한글도 깨지지 않아야 한다.
  - matplotlib 사용 시 `matplotlib.rcParams['font.family']`를 동봉 폰트로 지정하고 `axes.unicode_minus = False` 설정.
  - 또는 프론트엔드 차트를 PNG(base64)로 전달받아 삽입한다.
- **검증 테스트 필수:** 생성된 PDF에서 텍스트를 추출해 한글 문자열이 그대로 나오는지 자동 테스트로 확인한다.

### 3.2 PDF 구성
| 페이지 | 내용 |
|--------|------|
| 표지 | 리포트 제목, 호기명, 분석 기간, 실행자, 생성 일시, 회사/부서 |
| 1. 요약 | KPI 4종, 등급, 결론 문장(권고 사항), 주요 가정 |
| 2. 데이터 개요 | 데이터 기간, 총/유효/제외 포인트, 제외 사유별 표, 군집 분포 |
| 3. 예측 모델 | 알고리즘, 버전, 학습 기간, MAE/RMSE/R², 실측-예측 산점도 |
| 4. 오염도 분석 | FI 시계열 차트, 군집별 FI 표, 차압·스택온도 잔차 추이 |
| 5. 추세 및 도달 예측 | 추세 모델, 기울기, D-day, 신뢰구간, 등급 전환 예상일 |
| 6. 편익 분석 | 손실 출력, 일일 손실, 세정 비용, 순편익, 회수기간, 시나리오 비교표, 적용 파라미터 |
| 7. 세정 전후 비교 | (해당 시) 비교 표와 차트 |
| 부록 | 적용 설정값 전체 스냅샷, 모델 버전, 용어 설명 |

### 3.3 공통 요소
- 머리글: 호기명 + 리포트 제목 / 바닥글: 페이지 번호 `N / M`, 생성 일시
- 모든 수치 표에 단위를 명시
- 결론 문장은 템플릿 기반으로 생성하되 수치는 실제 결과를 사용한다.
  예) “1호기 HRSG의 현재 오염도 지수는 62.4(경고)이며, 임계치 60을 이미 초과했습니다. 현재 조건에서 세정 시 1년 순편익은 약 7.7억 원, 회수기간은 48일로 추정됩니다.”
- 가정과 한계를 명시하는 고정 문단을 포함한다(계수 기반 추정치임을 밝힘).

## 4. 엑셀 리포트 (FR-U-16)

### 4.1 기술 요건
- 라이브러리: **openpyxl**
- 시트명·헤더·값에 한글 사용, 인코딩 이슈 없음(xlsx는 UTF-8 기반)
- 열 너비 자동 조정, 헤더 고정(freeze panes), 숫자 서식(`#,##0`, `0.0`, `0.00`) 지정

### 4.2 시트 구성
| 시트명 | 내용 |
|--------|------|
| `요약` | KPI, 등급, 실행 정보(실행자/일시/기간/모델 버전) |
| `오염도지수` | 일자별 FI, 등급, 표본 수, 신뢰도 |
| `잔차상세` | 일자별 실측/기대/잔차 (차압, 스택온도) |
| `군집별분석` | 군집 키, 라벨, 표본 수, 평균 부하·외기온, FI |
| `모델정보` | 알고리즘, 버전, 학습 기간, 피처, 하이퍼파라미터, 지표 |
| `편익분석` | 손실·비용·편익 항목과 적용 파라미터 전체 |
| `추세예측` | 추세 계수, D-day, 신뢰구간, 등급 전환일 |
| `세정전후비교` | (해당 시) 군집별 비교 표 |
| `데이터품질` | 총/유효/제외 포인트, 제외 사유별 건수 |
| `설정값스냅샷` | 분석에 적용된 모든 설정 키-값 |

- 차트는 엑셀 네이티브 차트(`openpyxl.chart`)로 최소 1개(FI 시계열) 포함한다.

## 5. 생성 및 다운로드

- 엔드포인트: `POST /api/analysis-runs/{id}/export/` — body: `format`(`pdf`|`xlsx`), `charts`(base64 PNG 배열, 선택)
  - 비교 리포트는 `POST /api/comparisons/{id}/export/`, 다운로드는 `GET /api/reports/{id}/download/`
  > **정정 근거(2026-09-20):** 기존 `POST /api/analysis-runs/{id}/report/?format=` 는 API 정본인 `15-api.md` §9의 `/export/`와 불일치했다.
  > 엔드포인트 정의는 `15-api.md`를 정본으로 두고 이 문서를 맞췄다(형식은 쿼리스트링이 아닌 body 필드).
- 생성은 비동기로 처리하고 완료 시 다운로드 URL을 제공한다(소규모는 동기 응답 허용).
- 파일명 규칙: `HRSG오염도리포트_{호기코드}_{분석시작}_{분석종료}_{생성일시}.pdf`
  - 한글 파일명은 `Content-Disposition`에 RFC 5987 인코딩(`filename*=UTF-8''...`)으로 전달한다.
- 생성 이력(`ReportExport`)을 저장한다: 분석 실행, 형식, 생성자, 생성 일시, 파일 경로, 파일 크기.
- 생성된 파일은 `report_retention_days`(기본 90일) 후 정리한다.
