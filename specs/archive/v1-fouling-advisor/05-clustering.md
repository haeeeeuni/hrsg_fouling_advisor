# 05. 부하대·계절별 운전 구간 군집화

관련 요구사항: FR-U-06

---

## 1. 목적
차압과 스택온도는 부하와 외기 조건에 크게 좌우된다. 비교의 공정성을 확보하기 위해 운전 구간을 **부하대 × 계절(외기 조건)** 로 나누고, 이후의 기대값 모델링·오염도 산출·세정 전후 비교를 **같은 군집 내에서** 수행한다.

## 2. 군집화 방식

두 가지를 모두 제공하고 관리자가 기본 방식을 선택한다(기본: `RULE`).

### 2.1 규칙 기반 (`RULE`) — 기본
해석이 쉽고 보고서에 쓰기 좋다.

**부하대 (load band)** — 부하율 = `gt_power_mw / rated_power_mw × 100`
| 코드 | 범위 | 라벨 |
|------|------|------|
| `L1` | 40 ~ 60 % | 저부하 |
| `L2` | 60 ~ 80 % | 중부하 |
| `L3` | 80 ~ 95 % | 고부하 |
| `L4` | 95 % 초과 | 정격 |

**계절(season)** — 기본은 월 기준(`season_definition=MONTH`), 대안으로 외기온도 기준(`TEMP`)
| 코드 | 월 기준 | 외기온도 기준(대안) |
|------|---------|---------------------|
| `SP` | 3~5월 | 10 ~ 20 ℃ **이면서 상반기(1~6월)** |
| `SU` | 6~8월 | 20 ℃ 초과 |
| `FA` | 9~11월 | 10 ~ 20 ℃ **이면서 하반기(7~12월)** |
| `WI` | 12~2월 | 10 ℃ 미만 |

> **정정 근거(2026-09-20):** `TEMP` 모드에서 `SP`와 `FA`의 온도 범위가 10~20 ℃로 동일해 두 계절을 구분할 수 없었다.
> 봄·가을은 외기온만으로 나눌 수 없으므로 **해당 온도 구간에 한해서만** 월 정보를 병용해 가른다(나머지 구간은 온도만으로 결정).
> 기본값은 `MONTH`를 그대로 유지한다.

- 부하대 경계값과 계절 정의는 **DB 설정값**이며 호기별 오버라이드 가능.
- 군집 키: `{load_band}-{season}` (예: `L3-SU`)

### 2.2 데이터 기반 (`KMEANS`)
- 피처: `gt_power_mw`, `ambient_temp_c`, `exhaust_flow`(또는 대체), `gt_exhaust_temp_c`
- 표준화(`StandardScaler`) 후 `KMeans(n_clusters=k, random_state=RANDOM_SEED, n_init=10)`
- `k`는 기본 6, 관리자 설정. 실루엣 계수로 `k = 3~8` 범위 자동 추천 기능 제공.
- 각 군집에 대해 대표 조건(부하 평균, 외기온 평균, 샘플 수)을 산출해 **자동 라벨링**한다(예: “고부하·하계”).
- 군집 중심은 `ClusterModel`로 저장하여 이후 신규 데이터에 **동일 기준으로 할당**한다(재계산 시 군집 번호가 뒤바뀌지 않도록 중심 기준 매칭).

## 3. 군집 유효성 규칙
- 군집 내 유효 포인트가 `min_cluster_points`(기본 200) 미만이면 **희소 군집**으로 표시하고, 오염도 산출에서 가중치를 낮추거나 제외(설정).
- 오염도 종합 지수는 **군집별 지수를 표본 수 가중 평균**해 산출한다(`07-fouling-index.md` 참조).
- 세정 전후 비교, 호기 간 비교는 **양쪽 모두 유효 포인트가 있는 공통 군집**에 대해서만 수행한다.

## 4. 데이터 모델

```
ClusterDefinition
  - unit (FK), method ('RULE'|'KMEANS'), version, created_at, created_by
  - params : JSON (경계값 또는 k, 중심좌표, 스케일러 파라미터)
  - is_active

ClusterAssignment  (CleanedSeries에 컬럼으로 두어도 무방)
  - analysis_run(FK), timestamp, cluster_key, load_band, season
```

## 5. UI 표시
- 군집별 요약 테이블: 군집 키, 라벨, 포인트 수, 비중(%), 평균 부하율, 평균 외기온, 평균 차압, 평균 스택온도, 평균 FI
- 군집 분포 산점도(x=부하율, y=외기온, 색=군집)
- 희소 군집은 회색 처리 + “표본 부족” 배지

## 6. 예외 처리
| 상황 | 처리 |
|------|------|
| 유효 군집이 1개뿐 | 분석은 진행하되 “운전 조건 다양성 부족” 경고 |
| KMeans 수렴 실패 / 표본 부족 | 자동으로 `RULE` 방식으로 폴백하고 사유를 기록 |
| 신규 데이터가 기존 군집 중심에서 크게 벗어남(마할라노비스 거리 임계 초과) | `OUT_OF_DOMAIN` 플래그, 해당 구간의 기대값 신뢰도 낮음 표시 |
