# 20. UI/UX 가이드

## Spark Theme 사용
https://themewagon.com/themes/spark/ 무료 theme을 사용할 것

---

## 적용 방식 (2026-09-21 구현 시 결정)

Spark 는 **Bootstrap 5 기반 관리자 대시보드 템플릿**이므로 `AGENTS.md` §2 의 고정 스택
(Bootstrap 5 + 순수 CSS3, 그 외 UI 프레임워크 금지)과 충돌하지 않는다.

템플릿의 HTML 을 그대로 가져오는 대신 **디자인 토큰과 컴포넌트 스타일만 이식**한다.
이미 동작하는 화면 21종(`specs/16`)을 버리고 템플릿 마크업으로 갈아엎을 이유가 없고,
Bootstrap 의 CSS 변수를 덮어쓰면 기존 마크업이 그대로 테마를 따라가기 때문이다.

- 테마 정의: `frontend/src/assets/styles/spark-theme.css` 한 곳
- Bootstrap 5 의 `--bs-*` 변수를 재정의해 기존 유틸리티 클래스가 자동으로 테마를 따르게 한다
- 템플릿에서 **가져오지 않는 것**: ApexCharts(우리는 Chart.js — `specs/16` §1), flatpickr, 데모 이미지

### 디자인 토큰 (템플릿 `assets/css/main.css` 의 `:root`)

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--brand-forest-dark` | `#051C12` | 사이드바 배경 |
| `--brand-forest-medium` | `#072F1F` | 강조 카드 배경, 링크 |
| `--brand-lime` | `#B4F105` | 액센트 — 활성 메뉴, 기본 버튼 |
| `--bs-body-bg` | `#F4F6F5` | 캔버스 배경 |
| `--text-main` / `--text-muted-green` | `#0B130F` / `#6C7E75` | 본문 / 보조 텍스트 |
| 폰트 | Plus Jakarta Sans | 한글은 Pretendard 로 폴백 |
| 라운드 | `24 / 18 / 14 / 10 / 6 px` | 카드는 `--radius-xxl` |
| 사이드바 / 네비 | `280px` / `80px` | 레이아웃 고정값 |

### 레이아웃
템플릿과 동일하게 **전체 높이 고정 사이드바(좌) + 메인 영역 상단 네비게이션**으로 바꾼다.
기존의 "상단 네비 전체 폭 + 그 아래 사이드바" 구조에서 전환된다.

### 등급 색은 테마보다 우선한다
FI 등급(정상/주의/경고)의 초록·노랑·빨강은 **도메인 의미를 담은 색**이고
차트·배지·경고 배너가 공유한다(`specs/16` §8, `specs/11` §3).
라임(`#B4F105`)은 브랜드·상호작용 액센트에만 쓰고, `--bs-success/warning/danger`
의미 색은 덮어쓰지 않는다. 라임을 "정상"으로 오인하면 등급 판독이 무너진다.

### 접근성
`specs/16` §8 의 "색상만으로 정보를 전달하지 않는다" 규칙은 그대로다.
라임(`#B4F105`)은 밝아서 흰 배경 위 텍스트로 쓰면 대비가 부족하므로,
라임 배경에는 항상 진한 전경색(`--brand-forest-dark`)을 얹는다.
