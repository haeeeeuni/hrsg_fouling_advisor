# 11. 대시보드 및 시각화

관련 요구사항: FR-U-13

---

## 1. 목적
호기의 현재 오염 상태, 진행 추세, 의사결정 정보(도달 예상일, 예상 편익)를 한 화면에서 파악할 수 있게 한다.

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────────┐
│ [호기 선택 ▼]  [분석 기간: 2024-01-01 ~ 2024-12-31]  [분석 실행] │
│ 최근 분석: 2024-12-31 14:02 / 실행자 홍길동 / 모델 v3          │
├──────────────────────────────────────────────────────────────┤
│ ┌─ KPI 카드 4개 ──────────────────────────────────────────┐   │
│ │ 현재 오염도 지수 │ 등급 │ 임계 도달 D-day │ 예상 회수 편익 │   │
│ │      62.4        │ 경고 │   이미 도달     │  7.68억 원     │   │
│ └──────────────────────────────────────────────────────┘   │
├──────────────────────────────────────────────────────────────┤
│ ┌─ 오염도 지수 시계열 (메인 차트) ──────────────────────────┐  │
│ │ FI 라인 + 추세선 + 예측밴드 + 등급 배경 + 세정 마커        │  │
│ └────────────────────────────────────────────────────────┘  │
├──────────────────────────────────────────────────────────────┤
│ ┌ 차압 실측/기대 ┐ ┌ 스택온도 실측/기대 ┐ ┌ 군집별 FI 분해 ┐  │
├──────────────────────────────────────────────────────────────┤
│ ┌ 모델 정확도 ┐ ┌ 데이터 품질 요약 ┐ ┌ 편익 상세 ┐            │
├──────────────────────────────────────────────────────────────┤
│ [PDF 다운로드] [엑셀 다운로드] [세정 전후 비교]                │
└──────────────────────────────────────────────────────────────┘
```

## 3. KPI 카드 (필수 4종)

| 카드 | 표시 내용 | 부가 표시 |
|------|-----------|-----------|
| 현재 오염도 지수 | `62.4` (소수점 1자리) | 기준일, 전주 대비 증감(`▲ 3.2`), 신뢰도 배지 |
| 오염도 등급 | `경고` (색상 배지) | 등급 경계 범위 안내 툴팁 |
| 임계 도달 D-day | `D-84` 또는 `이미 도달` | 예상 도달일, 신뢰구간 |
| 예상 회수 편익 | `7.68억 원` | 순편익 기준임을 명시, 회수기간, 지연 비용(원/일) |

- 등급 색상: 정상 `success`(초록), 주의 `warning`(노랑), 경고 `danger`(빨강) — Bootstrap 5 컬러 토큰 사용.
- 색상만으로 의미를 전달하지 않는다(텍스트 라벨 병기 — 접근성).

## 4. 메인 차트 — 오염도 지수 시계열

| 요소 | 사양 |
|------|------|
| x축 | 날짜 |
| y축 | FI (0~100 고정) |
| 주 시리즈 | `FI_daily` 실선 |
| 추세선 | 점선, 예측 구간은 반투명 밴드 |
| 등급 배경 | 0~30 연초록, 30~60 연노랑, 60~100 연빨강 (매우 옅게) |
| 임계치 라인 | 수평 점선 + 라벨 |
| 세정 마커 | 수직선 + 아이콘, 툴팁에 일자·방법·비용 |
| 상호작용 | 호버 툴팁(일자, FI, 표본 수, 신뢰도), 기간 줌/브러시, 범례 토글 |
| 결측 구간 | 선을 잇지 않고 끊어 표시 |

## 5. 보조 차트

### 5.1 차압 실측 vs 기대
- 실측(실선)과 기대(점선) 시계열 오버레이, 하단에 잔차 바/영역 차트.

### 5.2 스택온도 실측 vs 기대
- 동일 구조.

### 5.3 군집별 FI 분해
- 가로 막대: 군집 키, FI, 표본 수, 비중. 희소 군집은 회색 + 배지.

### 5.4 모델 정확도 패널
- 차압/스택온도 각각 MAE, RMSE, R² 수치 + 양호·주의·불량 배지
- 실측 vs 예측 산점도(대각선 기준선)

### 5.5 데이터 품질 요약
- 총/유효/제외 포인트, 제외 사유별 막대, 유효 비율 게이지

### 5.6 편익 상세 패널
- 손실 출력(GT/ST 분해), 일일 손실 비용, 세정 비용, 순편익, 회수기간, 권고 세정 시점
- 시나리오 비교 표(지금 세정 / 임계 도달 시 / 계획 정비 시)

## 6. 시각화 공통 규칙
- 차트 라이브러리는 **Chart.js + vue-chartjs** 1종만 사용한다(`16-frontend.md` §1 확정). 혼용 금지.
- 모든 축에 단위 라벨을 표시한다(`FI`, `kPa`, `℃`, `원`).
- 숫자 포맷: FI 소수 1자리, 금액 천단위 구분 + 억 단위 병기, 온도 소수 1자리, 차압 소수 2자리.
- 데이터가 없으면 빈 차트 대신 **“데이터 없음” 플레이스홀더 + 원인 안내**를 표시한다.
- 로딩 중에는 스켈레톤 UI를 표시한다.
- 차트는 PNG로 내보낼 수 있어야 하며, 이 이미지는 PDF 리포트에도 재사용된다.

## 7. 상태 및 경고 배너
화면 상단에 조건부 배너를 표시한다.
| 조건 | 배너 |
|------|------|
| 청정 기준 기간 미지정 | “청정 기준 기간이 지정되지 않았습니다. 결과 신뢰도가 낮을 수 있습니다.” (경고) |
| 모델 지표 불량 | “예측 정확도가 낮습니다(R² 0.62). 모델 재학습을 권장합니다.” (경고) |
| 유효 데이터 비율 < 20% | “유효 운전 구간이 부족합니다.” (경고) |
| 단차(계측기 이상) 의심 | “계측값 급변이 감지되었습니다. 계측기 점검을 확인하세요.” (정보) |
| `must_change_password` | “초기 비밀번호를 변경해 주세요.” (정보) |

## 8. 분석 실행 UX
1. 호기·기간 선택 → [분석 실행] 클릭
2. 편익 파라미터 임시 변경 패널(접이식) — 기본값 대비 변경 항목 강조
3. 실행 → 진행률 표시(정제 → 군집화 → 예측 → 지수 → 추세 → 편익)
4. 완료 시 대시보드 자동 갱신, 실패 시 단계별 실패 사유 표시
5. 최근 분석 결과는 캐시되어 재진입 시 즉시 표시된다.

## 9. 반응형
- Bootstrap 5 그리드 기준: `xl` 4열 KPI, `md` 2열, `sm` 1열.
- 최소 지원 폭 1280px(사내 데스크톱 기준), 태블릿은 동작만 보장.
