# 10. 정비 이력 및 세정 이력 관리

관련 요구사항: FR-U-14, FR-A-06, FR-A-07

---

## 1. 목적
정비 이력 파일에서 오염·세정 관련 이력을 자동 추출하고, 확정된 세정 이력을 분석의 기준점(청정 기준 기간, 추세 절단, 전후 비교)으로 활용한다.

## 2. 정비 이력 파일 업로드 (FR-U-14)

### 2.1 지원 형식
- CSV (`.csv`), 엑셀 (`.xlsx`, `.xls`)
- 엑셀은 첫 시트를 기본으로 하되, 시트 선택 UI를 제공한다.

### 2.2 기대 컬럼 (유연 매핑)
| 표준 항목 | 필수 | 예상 원본 컬럼명 |
|-----------|------|------------------|
| `work_date` | ✔ | 작업일, 정비일자, 일자, Date |
| `unit_name` | – | 호기, 설비, Unit (없으면 업로드 시 선택한 호기로 지정) |
| `work_type` | – | 작업구분, 정비유형 |
| `title` | ✔ | 제목, 작업명 |
| `description` | – | 내용, 작업내역, 비고 |
| `cost` | – | 비용, 금액 |
| `duration_days` | – | 소요일수, 정지일수 |
| `worker` | – | 작업자, 담당 |

- 컬럼 자동 인식: 헤더명을 정규화(공백·괄호 제거, 소문자화)한 뒤 사전 매칭 → 실패 시 사용자에게 매핑 UI 제시.

## 3. 오염 관련 이력 자동 추출

### 3.1 키워드 사전 (FR-A-07)
```
FoulingKeyword
  - keyword        : 문자열 (예 '세정', '수세', '화학세정', '워터젯', '전열면 청소')
  - category       : 'CLEANING'(세정) | 'FOULING'(오염 징후) | 'INSPECTION'(점검) | 'EXCLUDE'(제외어)
  - weight         : 가중치 (기본 1.0)
  - is_active
  - created_by / created_at
```

기본 시드 키워드
| 분류 | 키워드 |
|------|--------|
| CLEANING | 세정, 수세, 화학세정, 건식세정, 워터젯, 드라이아이스, 전열면 청소, 핀 튜브 청소, 튜브 클리닝, soot blowing, cleaning |
| FOULING | 오염, 파울링, 회분 부착, 차압 상승, 스택온도 상승, 전열면 막힘, 스케일, 퇴적 |
| INSPECTION | 내부 점검, 개방 점검, 육안 점검 |
| EXCLUDE | 계획 없음, 취소, 미시행 |

### 3.2 추출 규칙
1. `title` + `description` 문자열에서 활성 키워드를 검색한다(대소문자 무시, 공백 제거 후 부분 일치).
2. `EXCLUDE` 카테고리 키워드가 포함되면 후보에서 제외한다.
3. 매칭 점수 = Σ(매칭 키워드 weight). 점수 ≥ `extraction_threshold`(기본 1.0)인 레코드를 후보로 제시한다.
4. `CLEANING` 매칭 레코드는 **세정 이벤트 후보**로, `FOULING` 매칭 레코드는 **오염 징후 이력**으로 분류한다.
5. 자동 추출 결과는 **바로 확정하지 않고** 사용자/관리자가 검토·승인해야 `CleaningEvent`로 등록된다(오탐 방지).

### 3.3 검토 화면
- 후보 목록: 일자, 제목, 매칭 키워드(하이라이트), 점수, 분류
- 각 행에 [세정으로 등록] / [오염 징후로 기록] / [무시] 버튼
- 일괄 승인 지원

## 4. 세정 이력 (FR-A-06)

```
CleaningEvent
  - unit (FK)
  - cleaned_at        : 세정 일자 (필수)
  - cleaned_end_at    : 종료 일자 (선택)
  - method            : 'WATER_WASH'|'CHEMICAL'|'DRY_ICE'|'MECHANICAL'|'SOOT_BLOWING'|'OTHER'
  - method_detail     : 자유 입력
  - cost              : 비용(원)
  - outage_days       : 정지 일수
  - source            : 'MANUAL'|'EXTRACTED'
  - maintenance_record: FK(nullable) — 추출 출처
  - note
  - created_by / created_at / updated_at
```

- 관리자는 세정 이력을 **추가·수정·삭제**할 수 있다.
- 같은 호기에서 세정 일자가 중복되면 경고(등록은 허용).
- 세정 이력 변경 시 다음에 영향을 주므로 **영향 범위 안내 후 확인**을 받는다.
  - 청정 기준 기간 자동 산정
  - 추세 구간 절단 지점
  - 세정 전후 비교 리포트
  - 대시보드 세정 마커
- 세정 이력 삭제 시 이를 참조한 분석 결과가 있으면 경고하되, 과거 결과는 **당시 스냅샷을 유지**한다.

## 5. 정비 이력 모델
```
MaintenanceRecord
  - unit (FK)
  - work_date, work_type, title, description, cost, duration_days, worker
  - upload_batch (FK)
  - is_fouling_related : bool
  - matched_keywords : JSON
  - match_score
  - review_status : 'PENDING'|'ACCEPTED'|'IGNORED'
```

## 6. 활용
| 활용처 | 방식 |
|--------|------|
| 청정 기준 기간 | 최근 세정 종료일 + offset부터 N일 |
| 추세 구간 | 최근 세정일 이후만 사용 |
| 대시보드 | FI 시계열 위 세정 수직 마커 + 툴팁(일자/방법/비용) |
| 전후 비교 | 세정일 기준 전 N일 / 후 N일 데이터 비교 |
| 세정 주기 분석 | 세정 간 평균 간격, 세정 시점 FI 분포 |
| 편익 실적 검증 | 예측 편익 vs 실제 회복량 비교(백테스트) |

## 7. 예외 처리
| 상황 | 처리 |
|------|------|
| 세정 이력이 하나도 없음 | 청정 기준 기간 수동 지정 요구 + 경고 배너 |
| 세정 일자에 해당하는 운전 데이터 없음 | 마커는 표시하되 전후 비교 불가 안내 |
| 키워드 사전이 비어 있음 | 기본 시드 복원 버튼 제공 |
| 엑셀 파일 파싱 실패 | 400 `EXCEL_PARSE_ERROR` + 시트/행 정보 |
