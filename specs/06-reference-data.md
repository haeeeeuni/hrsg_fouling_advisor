# 06. 참조 데이터와 계산 파라미터

관련 요구사항: REF-1 ~ REF-6

---

## 1. 목적

계산기가 쓰는 값 중 **실무 자료로 바뀔 것들**을 코드가 아니라 DB 에 두고, 관리자가 교체할 수 있게 한다.
지금은 전부 `[임시값]` 이다.

## 2. GT 운전 한계 참조표 (REF-1)

- **REF-1** GT 모델별 정격·설계값·한계값 표. 관리자가 추가·수정·비활성화하고, 스프레드시트(.xlsx)로 일괄 가져온다.

| 필드 | 단위 | 설명 |
|---|---|---|
| `name` | – | 모델 이름(유일) |
| `manufacturer` | – | 제조사 |
| `rated_gt_mw` | MW | GT 정격 출력 |
| `rated_st_mw` | MW | 연계 ST 정격(선택) |
| `design_backpressure_kpa` | kPa | 설계(청정) 배압 |
| `backpressure_alarm_kpa` · `backpressure_trip_kpa` | kPa | 배압 경보·트립 한계 |
| `design_exhaust_temp_c` | ℃ | 설계 배기온도 |
| `exhaust_temp_alarm_c` · `exhaust_temp_trip_c` | ℃ | 배기온도 경보·트립 한계 |
| `design_stack_temp_c` | ℃ | 설계 굴뚝 온도 |
| `is_placeholder` | bool | 임시값 여부 |
| `is_active`, `note`, `version` | | |

- 검증: `경보 < 트립`, 정격 > 0. 위반하면 저장하지 않는다.
- 수정하면 `version` 이 올라간다. 계산 결과는 사용한 모델의 버전을 남긴다(`05` CALC-10).

### 2.1 시드 `[임시값]`

**실존 모델명에 가짜 한계값을 붙이지 않는다.** 실제 사양으로 오해받을 수 있기 때문이다.

| name | rated_gt_mw | rated_st_mw | design_bp | bp_alarm | bp_trip | design_exh | exh_alarm | exh_trip | design_stack |
|---|---|---|---|---|---|---|---|---|---|
| 가상 모델 A (F급) | 270 | 135 | 3.0 | 4.5 | 5.5 | 610 | 640 | 660 | 95 |
| 가상 모델 B (H급) | 400 | 200 | 3.2 | 4.8 | 5.8 | 640 | 665 | 685 | 90 |
| 가상 모델 C (E급) | 170 | 85 | 2.8 | 4.2 | 5.2 | 560 | 590 | 610 | 105 |

- 전부 `is_placeholder=True`, 제조사는 "가상".
- `[실무 논의]` 실제 참조표(대상 모델, 판정 변수, 한계값). **받으면 관리자 모드에서 교체한다.**

## 3. 세정 공법 표 (REF-2)

- **REF-2** 공법별 비용·정지 일수·회복률. 관리자가 추가·수정·비활성화한다.

| name | cleaning_cost_won | outage_days | recovery_ratio | is_placeholder |
|---|---|---|---|---|
| 드라이아이스 세정 | 30,000,000 | 2.0 | 0.85 | ✔ |
| 화학 세정 | 80,000,000 | 4.0 | 0.95 | ✔ |
| 고압 수세정 | 20,000,000 | 3.0 | 0.75 | ✔ |

- 검증: 비용 ≥ 0, 정지 일수 ≥ 0, 0 < 회복률 ≤ 1.
- `[실무 논의]` 실적 기반 공법 목록과 값.

## 4. SMP (REF-3, REF-4)

- **REF-3** 관리자가 SMP 를 등록한다: 값(원/kWh), 기준일(또는 기간), 출처(예: "KPX 공개 자료"), 추정 여부.
  최신 기준일 값이 계산기 기본값이다. 이력은 지우지 않고 남긴다.
- **REF-4 공식 가격처럼 보이지 않게:** 계산기·챗봇 카드에 SMP 를 보여 줄 때 항상 **기준일과 출처**를 함께 표시한다.
  - 추정값이면 "추정" 배지, 사용자가 직접 바꾼 값이면 "사용자 입력" 배지를 붙인다.
  - 등록된 SMP 가 없으면 계산기는 SMP 입력을 필수로 요구하고 기본값을 채우지 않는다.
- KPX 자동 수집은 1차 범위 밖이다(`changes-2026-10.md` §3). 수동 등록으로 시작한다.

## 5. 계산 파라미터 세트 (REF-5)

- **REF-5** 손실 모델의 계수는 **버전이 있는 파라미터 세트**로 관리한다. 활성 세트는 하나다.

| 키 | 시드 | 단위 |
|---|---|---|
| `dp_power_loss_coeff` | 0.35 | %MW / kPa |
| `stack_temp_loss_coeff` | 0.12 | %MW(ST) / ℃ |
| `capacity_factor` | 0.85 | – |
| `fuel_cost_ratio` | 0.792 | – |
| `evaluation_horizon_days` | 365 | 일 |
| `default_operating_hours_per_day` | 20 | h/일 |

- 관리자가 값을 바꿔 저장하면 **새 버전**(예: `p3`)이 생기고 활성화된다. 이전 버전은 남아 있어 되돌릴 수 있다.
- 변경 화면에 이전 버전 대비 차이와 같은 예시 입력의 결과 변화를 미리 보여 준다.
- 핀치·어프로치 기준(`calc_pinch_range_c` 기본 5~15, `calc_approach_range_c` 기본 3~15, `calc_pinch_margin_c` 기본 3)도 이 세트에 둔다. `[임시값]`
- **관리자가 바꿀 수 있는 것은 계수와 표다. 식의 구조는 바꿀 수 없다.** 식은 코드(`formula_version`)이고,
  실무 확정 후 개발자가 교체한다(결정 2026-10-10 — 관리자 수식 편집은 검증·보안 부담에 비해 이득이 작다).

## 6. 임시값 표시 (REF-6)

- **REF-6** `is_placeholder` 인 참조값이나 시드에서 바뀌지 않은 파라미터 세트를 쓴 계산에는
  사용자 화면에 "임시 참조값을 사용한 결과입니다" 안내를 붙인다(`uses_placeholder`).
- 관리자 화면 목록에는 "임시값" 배지를 붙인다. 실무 자료로 교체하고 `is_placeholder` 를 해제하면 안내가 사라진다.

## 7. 수용 기준 (AC)

- [ ] AC-06-1 빈 DB 에서 `seed_defaults` 후 가상 모델 3개, 공법 3개, 파라미터 세트 `p1` 이 있고 전부 임시값이다. 두 번 실행해도 늘지 않는다.
- [ ] AC-06-2 경보 ≥ 트립인 GT 모델은 저장되지 않는다.
- [ ] AC-06-3 파라미터를 바꾸면 새 버전이 활성화되고, 이전 버전 결과는 `param_version` 으로 구분된다. 이전 버전으로 되돌릴 수 있다.
- [ ] AC-06-4 계산기에 SMP 의 기준일·출처가 항상 보이고, 사용자가 값을 바꾸면 "사용자 입력" 배지가 붙는다.
- [ ] AC-06-5 USER 권한으로 파라미터·한계값 원본 API 를 부르면 403 이다.
- [ ] AC-06-6 xlsx 가져오기에서 검증에 실패한 행은 행 번호와 사유를 보여 주고 나머지는 저장하지 않는다(전부 아니면 전무).
