### 3.1 원 요구사항 → ID

전달받은 요구사항(2026-10-10)과 RAG 챗봇 기술 프롬프트의 각 문장이 어느 ID 로 구현되는지 보인다.

| 원 요구사항 | ID |
|---|---|
| 기술 자료와 사례를 근거로 답한다 | CHAT-2, KB-7 |
| 수치는 계산기로 답하고 카드로 보여준다 | CHAT-3, LLM-6 |
| 한국어/영어 질문 지원 | CHAT-5 |
| AI 가 임의로 숫자를 만들지 않는다 | CHAT-4 |
| 원문·고객사·발전소·개인 정보·계산 방식 노출 금지 | CHAT-6, CHAT-7, KB-9, CALC-8, NFR-1 |
| 관리자가 API 키를 입력하지 않으면 채팅 비활성 | CHAT-8, LLM-3 |
| 상단 우측 ID/비밀번호 로그인 | AUTH-6, UI-2 |
| 기본 관리자 `admin` / `admin1234!` 자동 생성 | AUTH-9 |
| 회원가입 + 관리자 승인 (프롬프트의 "로그인 없음"을 대체) | AUTH-1 ~ AUTH-5 |
| 회사·제품 정보 CRUD, Text/Word/PDF 입력 | KB-1 ~ KB-4 |
| 회사·제품 정보를 pgvector 로 저장 | KB-5, KB-6 |
| LLM 3종(ChatGPT·Claude·Gemini) 중 선택 | LLM-1 |
| API 키는 관리자 화면에서 입력해 PostgreSQL 에 저장 | LLM-2 |
| 기본 모델 Claude Opus 5.5, 관리자가 변경 | LLM-4 |
| RAG 튜닝 설정(시스템 프롬프트 포함)을 DB 에 저장·관리자 변경 | KB-8, CHAT-9, ADM-5 |
| Embedding 방식 추천 | KB-5 |
| 계산기: 현재 상태·예상 손실·회수 효과 | CALC-1 |
| 계산기: 공법별 비용 비교 | CALC-3 |
| 계산기: 핀치·어프로치 점검 | CALC-4 |
| 계산기: 게이지·도식·그래프, 즉시 반응 | CALC-5, CALC-6 |
| 산정 방식 비공개 | CALC-8 |
| 추정값은 보수적으로 | CALC-9 |
| 확인되지 않은 가격을 공식 가격처럼 제시 금지 | REF-4 |
| 체크리스트: 양식 전 항목 + 핀치·어프로치 + 일정·현장 | CHK-1 |
| 체크리스트: 체크로 진행 관리, 이메일용 복사 | CHK-3, CHK-5 |
| 큰 숫자·상태 색, 한국어 기본, 라이트/다크, 대비 | UI-3 ~ UI-6 |
| 검수 시나리오 1~8 | ACC-1 ~ ACC-8 |
