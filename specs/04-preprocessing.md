# 04. 데이터 정제 및 운전 구간 필터링

관련 요구사항: FR-U-04, FR-U-05

---

## 1. 목적
오염도 산출에 부적합한 데이터를 제거하여, 정상 정격 운전 구간만으로 분석이 이루어지도록 한다.
오염 신호는 미세하므로 **잡음 제거가 정확도의 대부분을 결정한다.**

## 2. 전체 파이프라인

```
원본 Measurement (기간 선택 범위)
 └─ (1) 타임스탬프 정렬 / 중복 제거
 └─ (2) 결측치 처리
 └─ (3) 이상치 탐지 및 제거
 └─ (4) 리샘플링 (선택)
 └─ (5) 운전 구간 분류 및 제외 플래그 부여
 └─ (6) 유효 구간(Valid Segment)만 추출
 └─ 결과: 정제 데이터 + 제외 사유별 통계
```

모든 단계는 **원본을 수정하지 않고** 파생 테이블/플래그로 처리한다.

## 3. 분석 기간 선택

- 사용자는 분석 실행 시 시작일·종료일을 지정한다. 기본값은 **해당 호기 누적 데이터의 최근 12개월**.
- 빠른 선택: 최근 1개월 / 3개월 / 6개월 / 1년 / 전체 / 직접 지정.
- 선택 구간의 유효 데이터가 설정 하한(기본 500행) 미만이면 분석을 거부한다(`INSUFFICIENT_DATA`).

## 4. 결측치 처리

| 상황 | 처리 |
|------|------|
| 단일 항목 짧은 결측 (연속 ≤ `gap_fill_max_points`, 기본 3점) | 선형 보간 |
| 연속 결측이 임계 초과 | 해당 구간 전체 제외 (`EXCLUDE_MISSING`) |
| 필수 분석 항목(`hrsg_gas_dp_kpa`/`gt_backpressure_kpa`, `stack_temp_c`, `gt_power_mw`) 결측 | 해당 행 제외 |
| 선택 항목 결측 | 해당 항목을 피처에서 제외(모델 학습 시 자동 판단) |
| 컬럼 전체 결측률 > 50% | 해당 컬럼을 피처에서 제외하고 경고 표시 |

보간은 시간 기준(`method='time'`)으로 한다.

## 5. 이상치 탐지

순서대로 적용한다.

### 5.1 물리 범위 필터 (하드 필터)
`03-data-ingestion.md` 4.3의 범위를 벗어난 값은 NaN 처리.

### 5.2 통계적 이상치 (롤링 로버스트)
- 항목별로 이동 윈도(기본 **3시간**) 내 중앙값(median)과 MAD를 계산.
- `|x - median| > k × 1.4826 × MAD` (기본 `k = 5`) → 이상치.
- 짧은 스파이크만 제거하고, **지속적인 상승(오염 신호)은 제거하지 않아야 한다.**
- **운전 중(`gt_power_mw ≥ min_load_mw`) 구간에만 적용한다.** 정지 구간의 0/일정값은 정상이며, 이를 제거하면 기동·정지 전환점이 사라져 구간 분류가 무너진다. 고정값(Stuck) 탐지도 동일하다.

> **정정 근거(2026-09-20, Phase 3):** 원문은 "윈도를 24시간 이상으로 유지"하라고 했으나, 실측해 보니 그 반대였다.
> 주간·야간 부하 블록이 약 59 MW 차이나는 이봉분포에서 24시간 윈도의 중앙값은 다수인 주간 블록에 놓이고
> MAD가 작아져(≈1.2 MW) 임계가 8.8 MW가 된다 → **야간 블록 전체가 이상치로 오탐**된다.
> 샘플 데이터 24개월로 측정한 결과:
>
> | 윈도 | 부하 오탐 | 차압 오탐 | 인위적 스파이크 검출 |
> |------|----------|----------|--------------------|
> | 3h | 1,956 | 1,755 | 200/200 |
> | 12h | 4,068 | 2,692 | 180/200 |
> | 24h | 27,646 | 19,462 | 132/200 |
>
> 오염 drift 보호도 3시간에서 문제없다(180일간 +17 kPa 선형 증가 시계열에서 제거율 0.05%).
> 이상치 **탐지**는 국소 중앙값 대비 편차만 보므로, 윈도가 짧아도 완만한 추세는 편차가 0에 가까워 걸리지 않는다.
> 오히려 윈도가 길수록 정상적인 운전 변화를 이상치로 오인한다. 기본값을 3시간으로 확정한다.

### 5.3 고정값(Stuck) 탐지
동일 값이 연속 `stuck_points`(기본 30점) 이상 반복되면 계측기 고착으로 보고 해당 구간 제외(`EXCLUDE_STUCK`).

### 5.4 단차(Step Change) 탐지 — 경고용
차압·스택온도 시계열에서 계측기 교정/교체로 의심되는 급격한 레벨 변화(예: 인접 6시간 평균 차이가 표준편차의 5배 초과)를 탐지하면 **제외하지 않고 경고 배지**만 표시하고 관리자에게 확인을 요청한다.

### 5.5 설정
모든 임계값(`mad_k`, `rolling_window_h`, `stuck_points`, `gap_fill_max_points`)은 DB 설정값이며 호기별 오버라이드가 가능하다.

## 6. 리샘플링
- 분석 표준 주기는 호기 설정 `sampling_interval_min`(기본 10분).
- 원본 주기가 더 촘촘하면 시간 평균으로 다운샘플링한다(`duct_burner_on`은 `max`, 즉 한 번이라도 ON이면 ON).
- 다운샘플링된 구간의 유효 비율이 50% 미만이면 해당 구간을 버린다.

## 7. 운전 구간 분류 및 제외 규칙

각 시점에 `segment_state` 를 부여한다.

| 상태 | 판정 규칙(기본값, 모두 설정 가능) | 분석 포함 |
|------|--------------------------------|-----------|
| `STARTUP` | `gt_power_mw`가 `min_load_mw` 미만 → 이상으로 상승하는 구간 및 그 이후 `startup_settle_min`(기본 120분) | 제외 |
| `SHUTDOWN` | `gt_power_mw`가 `min_load_mw` 이상 → 미만으로 하강하는 구간 및 직전 `shutdown_lead_min`(기본 60분) | 제외 |
| `OFFLINE` | `gt_power_mw < min_load_mw` 지속 | 제외 |
| `LOAD_RAMP` | `|Δ gt_power_mw / Δt| > ramp_threshold_mw_per_min`(기본 1.0 MW/min) 또는 직전 `ramp_settle_min`(기본 30분) 이내 | 제외 |
| `DUCT_BURNER` | `duct_burner_on == True` 또는 OFF 전환 후 `db_settle_min`(기본 60분) 이내 | 제외 |
| `STEADY` | 위 어디에도 해당하지 않음 | **포함** |

추가 안정성 조건(모두 만족해야 `STEADY` 유지):
- 최근 `stability_window_min`(기본 30분) 동안 `gt_power_mw` 표준편차 < `load_std_max_mw`(기본 2.0 MW)
- 최근 동일 윈도 동안 `gt_exhaust_temp_c` 표준편차 < `exh_temp_std_max_c`(기본 5 ℃)
- `gt_power_mw ≥ min_analysis_load_pct × rated_power_mw` (기본 40%)

### 유효 구간(Valid Segment)
연속된 `STEADY` 시점들을 묶어 세그먼트로 만들고, 길이가 `min_segment_min`(기본 60분) 미만인 세그먼트는 버린다.

## 8. 산출물


## 9. 예외 처리
| 상황 | 처리 |
|------|------|
| 유효 포인트가 하한 미만 | `INSUFFICIENT_VALID_DATA` 오류, 완화 제안(기간 확대/임계값 조정) 안내 |
| 유효 비율 < 20% | 분석은 수행하되 “데이터 품질 주의” 경고 표시 |
| 덕트버너 컬럼이 항상 ON | 경고 표시 및 덕트버너 제외 규칙 비활성화 옵션 안내 |
