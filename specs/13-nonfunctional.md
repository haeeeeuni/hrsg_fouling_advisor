# 13. 비기능 요구사항

관련 요구사항: NFR-1 ~ NFR-8

---

## 1. 보안 (NFR-1, NFR-2)

- **NFR-1 노출 금지 목록.** 다음은 USER 화면·USER API·LLM 요청·로그 어디에도 나가면 안 된다.

  | 대상 | 막는 곳 |
  |---|---|
  | 문서 원본 파일·전체 본문 | 관리자 API 에서만 제공(`03` §8) |
  | 고객사·발전소 이름, 개인 정보 | 비식별화(사람) + 민감어 검사·가림(`03` KB-9, `02` CHAT-7) |
  | 계산식·계수·한계값 원본 | 서버 전용 계산, 결과만 응답(`05` CALC-8) |
  | LLM API 키 | 암호화 저장, 응답·로그·감사 로그 제외(`04` LLM-2) |
  | 비밀번호 | 해시 저장, 로그·스냅샷 제외 |

- **NFR-2 비밀 관리.** `SECRET_KEY`, `FIELD_ENCRYPTION_KEY`, DB 비밀번호는 환경 변수. 저장소에 커밋하지 않는다.
  `prod` 설정은 `SECRET_KEY` 가 플레이스홀더이거나 50자 미만이면, 또는 `FIELD_ENCRYPTION_KEY` 가 없으면 기동을 거부한다.
- 업로드: 확장자·MIME·크기 검증, 암호 파일 거부. 파일은 DB 에만 저장하고 실행 경로에 쓰지 않는다.
- xlsx 내보내기: 셀이 `=`, `+`, `-`, `@` 로 시작하면 수식 인젝션 방지 처리.
- 프롬프트 인젝션: 문서·사용자 입력의 지시문을 따르지 않도록 고정 보호 규칙을 두고, 출력 검사는 코드에서 한다(`02` §4·§5).
- 스로틀: 로그인 IP 분당 10회, 가입 IP 시간당 10회, 채팅은 사용자 하루 한도(`02` CHAT-10).

## 2. 성능 (NFR-3)

- **NFR-3**

  | 항목 | 기준 |
  |---|---|
  | 계산 API | p95 ≤ 300ms (즉시 반응, `05` CALC-6) |
  | 화면 첫 표시 | 3초 이내(데스크톱, 일반 사내망) |
  | 질의응답 | 검색 단계 p95 ≤ 1초. 전체는 공급자 응답에 좌우되며 상한 `llm_total_deadline_seconds` |
  | 문서 색인 | 20MB PDF 기준 5분 이내 |
  | 동시 사용 | 동시 사용자 20명에서 계산 API 기준 유지 |

## 3. 견고성 (NFR-4)

- **NFR-4** 외부 의존(LLM 공급자, 임베딩 실패)이 실패해도 앱이 멈추지 않는다.
  - 계산기·체크리스트는 LLM·임베딩 없이 동작한다.
  - 모든 외부 호출에 시간 제한을 둔다. 무한 대기 금지.
  - 프론트는 네트워크 오류·5xx 에서 안내 토스트를 보이고 화면을 유지한다. 전역 오류 경계에서 흰 화면을 막는다.
  - 서버 오류 응답에 스택 트레이스·내부 경로를 넣지 않는다.

## 4. 재현성 (NFR-5)

- **NFR-5** 계산 결과는 입력·파라미터 버전·식 버전·참조값 버전·SMP 기준일로 재현할 수 있다(`05` CALC-10).
  챗봇 메시지는 출처(문서 ID·버전)·계산 카드·공급자·모델을 저장한다. LLM 답변 자체는 결정적이지 않으므로 재현 대상이 아니다.

## 5. 호환성 (NFR-6)

- **NFR-6** 데스크톱 Chrome·Edge 최신, 모바일 Chrome(Android)·Safari(iOS) 최신. 폭 360px 이상(`12` §5).

## 6. 배포 (NFR-7)

- **NFR-7** 기존 배포 경로를 유지한다: 데모 Render(`render.yaml`), 운영 `docker-compose.prod.yml` + Nginx(`DEPLOY.md`).
  전환 시 바뀌는 것:

  | 항목 | 변경 |
  |---|---|
  | DB 이미지 | `postgres:16-alpine` → pgvector 포함 이미지(예: `pgvector/pgvector:pg16`) |
  | DB 확장 | 마이그레이션에서 `vector`, `pg_trgm` 생성 |
  | Render DB | 관리형 PostgreSQL 의 pgvector 지원 여부를 **구현 전에 확인**한다. 안 되면 데모 DB 구성을 다시 정한다 |
  | 환경 변수 | `FIELD_ENCRYPTION_KEY`(필수), `EMBEDDING_MODEL`(기본 `intfloat/multilingual-e5-small`) 추가 |
  | 이미지 | 임베딩 모델 파일을 빌드 시 내려받아 포함(기동 시 다운로드 금지) |
  | Gunicorn | `timeout` > 240초(`04` LLM-8) |
  | Celery | 문서 색인용으로 유지. Render 무료 플랜은 워커가 없어 즉시 실행(eager)이므로, 데모에서는 큰 문서 색인이 요청 시간을 넘길 수 있다 — 데모 문서는 작게 유지한다 |
  | 의존성 정리 | 이전 앱 전용(pandas·scikit-learn·scipy·ReportLab·matplotlib 등)은 전환 후 제거 — 이미지·메모리 절감 |

- **메모리 위험:** Render 무료 인스턴스(512MB)에 임베딩 모델을 올리면 부족할 수 있다(이전 앱이 분석 중 OOM 으로 죽은 적 있다).
  구현 첫 단계에서 실측하고, 부족하면 외부 임베딩 API 로 바꾼다(`03` §5).
- 헬스체크: `/api/health/live/`(프로세스), `/api/health/ready/`(DB + `vector` 확장 확인).

## 7. 로그 (NFR-8)

- **NFR-8** 애플리케이션 로그에는 요청 메타데이터(사용자 ID, 경로, 상태, 소요 시간, 오류 코드)만 남긴다.
  질문·답변 본문, 문서 본문, API 키, 비밀번호는 남기지 않는다.
